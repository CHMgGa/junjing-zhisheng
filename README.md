# 菌境智生：羊肚菌智慧种植调控系统

本仓库用于存放“菌境智生：羊肚菌智慧种植调控系统”比赛项目代码。

## 目录说明

- backend：后端服务与 MySQL 数据管理
- web：Web 管理端与农户端
- android：安卓移动端
- hardware：嵌入式采集与控制端
- digital-twin：数字孪生大棚展示端
- ai-assistant：智慧小菇 AI 助手
- yolo：YOLO 病虫害识别模块

## 上传注意事项

请不要上传数据库密码、云平台密钥、API Key、真实账号密码等敏感信息。
如果代码中需要配置文件，请上传 `.env.example` 或示例配置文件，不要上传真实 `.env` 文件。
请不要上传 `node_modules`、`dist`、`build`、`target`、`.idea`、`.gradle` 等本地依赖、构建产物或 IDE 缓存文件。
YOLO 模型文件如体积较大，可随比赛材料单独提交，仓库中保留推理代码和使用说明即可。
