# Junjing Zhisheng

Smart morel greenhouse project source code.

- `backend/`: backend service and MySQL data management
- `web/`: web management and farmer portal

Security note: this repository does not include real `.env` files, database passwords, cloud platform keys, API keys, or production account passwords. Start from each module's example configuration file and create real configuration only on your local machine.
